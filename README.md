## The entry

> I was never the AI. I was the loading screen, and you believed in me for three years.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (no trailing newline), with mode 0644. The output is deterministic: every run produces byte-identical output.
